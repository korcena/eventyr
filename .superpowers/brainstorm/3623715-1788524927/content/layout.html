App Layout — which feels right?

Main workspace layout for an event. Consider navigation, information density, and how todos/pages/shortcuts coexist.

A

Sidebar + Tabs (Notion-style)

Left sidebar: list of events you're in. Right: tabs for the selected event (Overview, Todos, Pages, Shortcuts, Settings). Clean separation, one active section at a time.
